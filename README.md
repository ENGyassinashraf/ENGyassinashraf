## 🚀 Featured Project

### ATLAS — Academic Tracking & Learning Assessment System

**Team of 6 · ASP.NET Core Web API · Clean Architecture · CQRS · EF Core · SQL Server**

An academic platform deployed college-wide and serving all four academic batches. My work included back-end architecture, relational data modeling, API development, and security-focused features.

- Designed a layered back-end using **Clean Architecture** and **CQRS**.
- Implemented **JWT authentication**, **BCrypt password hashing**, and **role-based access control** for Super Admin, Doctor, Teaching Assistant, and Student roles.
- Added audit logging for grade changes and validation to protect data integrity.
- Built REST endpoints documented with **Swagger/OpenAPI** for web and mobile clients.
- Contributed to user, course, and enrollment management, bulk Excel import, coursework-mark calculations, and PDF/Excel reports.
